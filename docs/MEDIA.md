# Documentation media

The screenshots and videos in this directory were captured from Photo Lab running locally in Google Chrome. They show the implemented interface rather than design mockups. Captures used an isolated browser profile, real photos from a Pexels curated API response, and sample favorites, collections, and a moodboard. The same cached API response was used across captures to keep the photo selection consistent.

The screenshots are JPEG files under [`images/`](images/), compressed for repository use. Desktop captures are 1440 pixels wide; mobile captures are 390 pixels wide. Heights vary to show the relevant workspace controls.

## Videos

Both recordings are silent WebM videos using VP8 at 1440 × 1000. Open them in a browser with WebM support or download them for playback. Repository viewers may show a download link instead of an inline video player; the README uses linked screenshots as previews.

- [Photo tools walkthrough](videos/photo-tools-walkthrough.webm) (40 seconds): themes, photo details, saving a collection, image adjustments, crop presets, a text overlay, image export, and comparison.
- [Moodboard walkthrough](videos/moodboard-walkthrough.webm) (25 seconds): creating and naming a board, selecting photos, collage layout, canvas zoom and pan, recovery after removal, and PNG export.
